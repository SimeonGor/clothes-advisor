# Clothes Advisor

В каталоге `frontend` выполните `npm ci`, затем `npm run dev` и откройте `/app/`.
По умолчанию API проксируется на `http://127.0.0.1:8080`; другой адрес задаётся через
`VITE_API_PROXY`. Команда `npm run build` собирает приложение в `dist` с базовым путём
`/app/`. `npm test` запускает проверки интерфейса.

Выбор активного аккаунта — тестовый переключатель, а не авторизация. При смене
аккаунта очищается кеш. Во время записи переключение и ссылки приложения недоступны.

- USER: «Сегодня» для AI-подбора, свой гардероб с загрузкой JPEG/PNG, ручные образы,
  история оценок и «Доступ стилистам» для выдачи и отзыва доступа.
- STYLIST: «Клиенты» → гардероб владельца для просмотра вещей и фото; «Образы владельца»
  для создания образов и оценки работ других авторов. Собственный гардероб и образы
  доступны через основное меню.
- ADMIN: «Аккаунты» → роль и статус с проверкой версии; вкладки владельца для
  модерации фото и удаления образов. Собственные вещи и образы редактируются через
  основное меню. Самоблокировка и понижение собственной роли недоступны.

При конфликте версии данные формы сохраняются; кнопка обновления явно заменяет их
актуальными значениями. Запись автоматически не повторяется. Права проверяет сервер.
Незавершённые попытки создания сохраняют свои ключи в пределах вкладки, аккаунта и
адреса запроса, в том числе после изменения данных и возврата к прежним. В хранилище
остаются только отпечатки и ключи, без содержимого форм и фото. Успех завершает только
соответствующую попытку; подтверждённая «Новая попытка» сбрасывает только последнюю
отправленную. После ошибки AI проверьте сохранённые данные: повтор с тем же ключом
не запускает уже принятую команду заново.
Для AI нужны серверные настройки; фотографии выбранных вещей передаются OpenAI.

Текущий публичный API не предоставляет авторизацию, регистрацию, создание аккаунта,
профиль/мерки, получение погоды по местоположению или редактирование готового образа.
Эти возможности потребуют расширения API.
