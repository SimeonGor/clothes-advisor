# Проверка схем

7 октября 2026 года. PlantUML 1.2025.10, Smetana, OpenJDK 25.0.3 — инструменты локального рендера, не выбор версии Java для приложения.

| Схема | PNG | Результат |
|---|---|---|
| architecture | 1398 × 858 | PNG без нижней легенды открыт: видны пять модулей одного монолита, три роли, PostgreSQL, приватный S3 и OpenAI; текст читается. |
| domain | 1475 × 619 | PNG без заголовка и легенды открыт: 13 сущностей, PK/FK/UK и кардинальности Crow’s Foot читаются; подписи CASCADE и RESTRICT видны. Архивных таблиц и статуса архивирования вещи нет. |

ER-модель содержит 16 связей внешних ключей. Автоматически сверено покрытие всех FK связями, отсутствие архивных сущностей и статуса вещи, отсутствие лишних полей в ManyToMany разрешений. История вещи не имеет FK на удаляемую вещь; история оценок не имеет FK на удаляемый образ или текущую оценку, но ссылается на стилиста. Исторические ID остаются в составных ключах.

С требованиями сверены запрет удаления используемой вещи, удаление остальных текущих зависимостей, сохранение истории и последней версии перед DELETE, атомарность и защита от конкурентных изменений. Файлы S3 сохраняются приватно без выдачи; история не является полным архивом удалённого объекта. Независимое чтение модели и требований существенных противоречий не выявило. Это проверка проекта, а не выполненные тесты приложения.

PNG/SVG созданы без ошибок; XML обеих SVG проверен через `xmllint --noout`. Визуально проверен новый PNG ER: текст и ключи читаются, подписи не обрезаны, наложений текста не обнаружено. Вертикальная компоновка сохранена. Архитектура не менялась и сохраняет предыдущую визуальную проверку. Схема БД требует согласования с преподавателем; 3НФ ещё не раскрытых характеристик и метаданных этой проверкой не подтверждается.

Повторить из корня проекта с [PlantUML 1.2025.10](https://repo.maven.apache.org/maven2/net/sourceforge/plantuml/plantuml/1.2025.10/plantuml-1.2025.10.jar):

```sh
PLANTUML_JAR=/absolute/path/plantuml.jar
java -Djava.awt.headless=true -jar "$PLANTUML_JAR" -charset UTF-8 -failfast2 -tpng docs/architecture.puml docs/domain.puml
java -Djava.awt.headless=true -jar "$PLANTUML_JAR" -charset UTF-8 -failfast2 -tsvg docs/architecture.puml docs/domain.puml
xmllint --noout docs/architecture.svg docs/domain.svg
```

После изменения исходника заново отрисовать и открыть соответствующий PNG. SHA-256 проверенных исходников:

```text
architecture.puml  1952b6f19858d9bd62518abd0f5d9cae7de8cd67cd2efdc5108e8c4452cd8995
domain.puml        f8689ab8cc9263c80d7ac70244af56bb8db7c233f63a95f1cae2e423915aca4a
```

Это проверка документов, не тесты приложения. Первый этап прошёл пользовательское ревью; согласование схемы БД с преподавателем остаётся отдельным шагом.
